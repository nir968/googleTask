A static web search interface inspired by Google Search, built using **HTML**, **CSS**, and **Bootstrap**. This project replicates the look and feel of a search engine, with search results related to the game **GTA V**.

## 🚀 Features
- Search page with a text box and search button
- Results page displaying static, pre-defined search results
- Clean and simple design inspired by Google, using only HTML, CSS, and Bootstrap

## 🛠️ Technologies
- **HTML** – Structure
- **CSS** – Styling
- **Bootstrap** – Responsive design and layout
